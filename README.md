# Tyler's Japan Earth

A personal, Google Earth–style 3D guide to Japan for a once-in-a-lifetime trip. Built on CesiumJS with Google Photorealistic 3D Tiles (via Cesium ion's free Community plan).

- `places.js` — layers and places (edit here to add spots)
- `app.js` — map, cards, Series plan, private journal (stored only in the browser)
- Cesium token is read-only and restricted to https://tds987.github.io
